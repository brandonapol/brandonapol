## Hello!

My name is Brandon. I am a self-taught programmer who quit teaching music in 2021 after I started learning JavaScript during lockdowns. 

I learned Python and React as well from CodeCademy in 2020, then took a software bootcamp in 2021. About halfway through the bootcamp I was offered a job teaching there upon graduation, because I had already learned the basics reasonably well and I had half a master's degree in elementary education at that point. 

I wound up working as a curriculum developer and invented their self-paced coursework, which was like a hybrid of pre-made educational videos plus "office hours" and a Slack server where students could get individualized attention. This way they weren't locked to a learning schedule or physical location, but they could get help if they needed it. I am still very proud of that product.

In 2023 I moved to Ohio and began working at Radiance Technologies as a "normal" software engineer. I started as a fullstack engineer working Angular and NodeJS, then moved into Jenkins and CI, migrated a project from Vue 2 to Vue 3 and taught the other developers about the Composition API and functional-style programming. Later I became the tech lead of a project that was essentially a Tanstack/React table as a Jira plugin for database management, and spent a lot of time on that project making our CI and devops bulletproof. As tech lead I also oversaw the removal of around 50,000 lines of code and simplified the application from about seven microservices to two.

After about a year of being tech lead, I moved to a new project working on authorization software for Radiance. I co-founded the Site Reliability Engineering practice there, which is a role I'm really passionate about, and continue to develop and grow in. Along with two friends, I mentor a team of about twelve engineers now. I also spent a lot of time over the last two years helping pilot and coach agentic programming for the company.

For personal projects and side quests, I've created birchwood.lol which is a personal recipe site; I have several ChatGPT plugins that I'm experimenting with; and I'm the less-engineering-more-design half of https://autobutler.org and github.com/autobutler-org/quark.
